# 🍽️ Animated Recipe Application

## 📌 Project Description
The **Animated Recipe Application** is a simple web-based project that allows users to explore different recipes with an attractive and animated user interface. It helps users view ingredients and cooking steps in an easy and interactive way.

## ✨ Features
- View and explore recipes  
- Smooth CSS animations  
- Simple and clean UI  
- Responsive design  

## 🛠️ Technologies Used
- HTML  
- CSS (Animations)  
- JavaScript  

## 🎯 Purpose
This project is created to practice frontend development skills and improve UI/UX using animations in a real-world style application.

## 🚀 How to Run the Project
1. Download or clone the project  
2. Open `index.html` in any modern web browser  
3. Start exploring recipes
